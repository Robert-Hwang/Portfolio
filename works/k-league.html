Main Website Case · 2021.02

대전하나시티즌

공식 홈페이지 메인·서브 페이지 디자인

Website Renewal

구단에서 전달한 사이트맵을 바탕으로 메인 UI를 디자인하고, 팀원·개발자와 구현 및 수정 사항을 조율하며 홈페이지 구축에 참여했습니다.

프로젝트 개요
대전하나시티즌 공식 홈페이지 리뉴얼
담당 역할
메인 페이지 UI 단독 디자인 상세 콘텐츠 UI 팀 협업 개발 협업

해결 과제

경기 일정, 선수 정보, 구단 소식 등 다양한 콘텐츠를 팬들이 빠르게 확인할 수 있도록 정보의 우선순위와 메인 화면 구성을 정리했습니다.

접근 방식

대전하나시티즌의 버건디와 그린 컬러를 적극적으로 활용해 구단의 아이덴티티를 강조하고, 주요 콘텐츠의 우선순위를 정리해 메인 화면을 구성했습니다.

이후 PC 화면을 기준으로 모바일 환경에 맞게 레이아웃을 재구성했습니다.

Main Page

  1. 01

    콘텐츠 우선순위

    경기 일정과 주요 구단 소식을 첫 화면에서 빠르게 확인할 수 있도록 구성

  2. 02

    브랜드 아이덴티티

    대전하나시티즌의 버건디와 그린 컬러를 주요 UI와 비주얼 요소에 일관되게 적용

  3. 03

    모바일 대응

    PC 화면의 구성과 비주얼을 바탕으로 모바일 환경에 맞게 주요 요소를 재배치

Current Site Note

현재 운영 중인 메인 화면으로, 메인 UI 및 레이아웃은 제 디자인을 기반으로 하며 이미지와 일부 콘텐츠는 이후 운영 과정에서 변경되었습니다.

Sub Page

메인 화면뿐 아니라 경기 정보와 구단 콘텐츠 등 하위 페이지에서도 동일한 디자인 방향과 콘텐츠 위계를 유지해 사이트 전체가 하나의 흐름으로 이어지도록 구성했습니다.
