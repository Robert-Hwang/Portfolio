# 대표 프로젝트 이미지 제작 가이드

PC(1101px 이상)에서는 왼쪽 위에 Selected Works 제목을 놓고, 오른쪽 위에 플레이도기, 왼쪽 아래에 신라명과, 오른쪽 아래에 K리그를 배치합니다. 프로젝트 이미지 3개는 모두 같은 정사각형 크기입니다. 태블릿·모바일(1100px 이하)에서는 제목 다음에 프로젝트 3개를 한 열로 표시합니다.

| 프로젝트 | 제작 크기 | 비율 | 권장 파일명 |
| --- | --- | --- | --- |
| PLAYDOGGY | 1600 × 1600 px | 1:1 | playdoggy-cover.webp |
| SHILLA BAKERY | 1600 × 1600 px | 1:1 | shilla-cover.webp |
| K LEAGUE | 1600 × 1600 px | 1:1 | kleague-cover.webp |

- sRGB로 제작하고 WebP 또는 JPG로 내보내세요. 원본 PSD·AI는 따로 보관하세요.
- 프로젝트명과 작은 설명은 웹에서 덧씌우므로 이미지에 중복해서 넣을 필요가 없습니다.
- 아래쪽 20%에는 프로젝트명이, 왼쪽 위에는 순번이, 오른쪽 아래에는 화살표가 표시됩니다. 중요한 화면·제품·문구는 중앙 70~80% 안에 배치하세요.
- 목업만 작게 띄우기보다 실제 UI나 콘텐츠를 크게 보여주는 구성이 좋습니다. 테두리와 라운드는 사이트에서 처리합니다.
- 이미지마다 700KB 안팎을 시작점으로 삼고, 작은 글자가 뭉개지지 않는 수준에서 조절하세요.
- 현재 기존 이미지(project-01.webp, project-06.webp, project-02.webp)는 임시 배치입니다. 작업 내용이 잘리지 않도록 `object-fit: contain`을 사용했습니다.
- 새 파일은 위 이름으로 `assets/`에 넣고, `index.html`의 해당 프로젝트 `<img src>`를 바꾸면 됩니다. 권장 비율대로 만들면 여백 없이 채워집니다.

## 반영한 방향

참고: https://midu.design/

기존 섹션 순서와 프로젝트 내용은 유지했습니다. 메인과 마지막에는 채도를 낮춘 노란색 면과 그 안에 섞여 드러나는 이름 타이포를 사용합니다. Skills는 밝은 회색 배경과 8개 도구 아이콘 및 D/W/C/L 카드로 구성하며, 일하는 방식 카드도 둥근 사각형으로 맞췄습니다.
