# Portfolio typography

- Latin letters and numerals: Switzer, by Indian Type Foundry.
- Main English headings and name wordmarks: Medium (500).
- Supporting text uses the existing 300–700 weight hierarchy.
- Korean: Noto Sans KR, selected through the same font stack for Hangul glyphs.

The Switzer webfont is served by the official Fontshare API. Font files are not bundled in this repository.

- Font family: https://www.fontshare.com/fonts/switzer
- Official license: https://www.fontshare.com/licenses/itf-ffl
- CSS endpoint: https://api.fontshare.com/v2/css?f[]=switzer@300,400,500,600,700&display=swap

The shared stack is `--font-ui` in `css/style.css`. The home page and project pages load the same Fontshare stylesheet.
